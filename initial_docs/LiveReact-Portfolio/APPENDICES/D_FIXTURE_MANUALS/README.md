# D — Fixture Manuals

Manufacturer documentation for the rig's fixtures, where available.

## What's here

- **`SHEHDS_180W_Moving_Head_Manual.pdf`** — Original SHEHDS manual for the 180W beam moving heads. Includes the full DMX channel chart in multiple modes, mechanical specs, and operating limits.

## What isn't here

The SHEHDS 3W laser and the OK-103-288WL wash bar manuals were not retained in PDF form. Their **DMX channel maps** are fully documented in `02_HARDWARE_RIG.md` (sections 3.2 and 3.4 respectively) and were verified during v1 build.

If you ever need the original manufacturer PDFs:
- SHEHDS laser: contact SHEHDS support (model number 3W RGB laser, 12ch/25ch DMX)
- OK-103-288WL wash bar: search "OK-103-288WL DMX manual" — generic Chinese-manufactured wash bar, multiple resellers have PDFs

The RGBW pars are generic 4-channel units; there is no fixture-specific manual to consult. Channels 1–4 are R / G / B / W as documented in `02_HARDWARE_RIG.md` section 3.3.

## How to use these

You shouldn't need them often. The relevant info (channel layouts, defaults, safety limits) is in `02_HARDWARE_RIG.md`. The PDFs are here as canonical source-of-truth in case the secondary doc is wrong.
